# Music Box Teleprompter

Teleprompter de letras e cifras para músicos. A tela é escura, com letras amarelas, e o pedal só rola o texto: ele funciona como um teclado (Page Down desce, Page Up sobe).

## Baixe a versão para o seu aparelho

| Arquivo | Para quê |
|---|---|
| [MusicBox.apk](https://github.com/MusicBoxLabs/Teleprompter/releases/latest/download/MusicBox.apk) | Celular ou tablet Android |
| [MusicBoxTeleprompter-Setup.exe](https://github.com/MusicBoxLabs/Teleprompter/releases/latest/download/MusicBoxTeleprompter-Setup.exe) | Windows (PC ou notebook) |
| [MusicBoxTeleprompter.AppImage](https://github.com/MusicBoxLabs/Teleprompter/releases/latest/download/MusicBoxTeleprompter.AppImage) | Linux |

## O que todas as versões têm em comum

- Mesma aparência e mesmo uso em todos os aparelhos.
- Pastas de músicas, com músicas em arquivos .txt.
- Importar músicas: um arquivo .txt, vários arquivos ou um .zip. O .zip vira uma pasta nova, com o nome do próprio .zip.
- Renomear, apagar e mover músicas entre pastas.
- O tamanho da letra se ajusta sozinho, para a linha mais longa da música caber na tela.
- Funciona com pedal por cabo USB ou Bluetooth. Também dá para rolar tocando na tela.
- Mostra se o pedal foi detectado: "PEDAL NÃO DETECTADO", "PEDAL BLUETOOTH" ou "PEDAL VIA CABO" (no Android).

## Android (APK)

1. Baixe o MusicBox.apk e abra o arquivo.
2. Se o Android pedir, permita instalar apps de fora da loja.
3. O app gira com o aparelho. Para ver na Smart TV, use "Espelhar na Smart TV" nas Configurações.
4. Para colocar músicas: use IMPORTAR no app, ou compartilhe o .txt ou .zip de outro app para o Music Box.

## Windows e Linux

- Windows: execute o instalador e siga as telas. As músicas ficam em Documentos\MusicBox.
- Linux: dê permissão de execução ao arquivo (botão direito → Propriedades → Permitir executar) e abra.
- F9 gira a tela: normal, em pé 90° ou em pé 270° (para monitor de palco girado). F11 liga a tela cheia. Esc volta.
- Arraste arquivos .txt ou .zip para dentro da janela para importar.

## Observações

- O Windows pode mostrar o aviso "O Windows protegeu o computador". Clique em "Mais informações" e depois em "Executar assim mesmo". O instalador ainda não tem assinatura digital paga.
- O código-fonte completo (app Android, versão de PC e firmware do pedal ESP32-S3) está neste repositório.
-  Um pedal (via cabo ou bluetooth) para rolar as cifras você encontra em https://musicboxteleprompter.com.br.
